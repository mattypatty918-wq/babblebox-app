# Translate Now

Multi-language translation app with camera OCR scanning. Translate text, signs, documents, and more — instantly.

## Features
- Real-time camera translation
- OCR document scanning
- 100+ language support
- Offline mode
- Translation history

## Build
```bash
npm install
npx cap sync
npx cap open android  # Android
npx cap open ios      # iOS
```

## Tech Stack
- React + Vite
- Capacitor
- iOS & Android
